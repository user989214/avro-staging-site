{%- comment -%}
  ============================================================================
  AVRO — GOLF TICKER  (standalone Shopify Online Store 2.0 section)
  ----------------------------------------------------------------------------
  A simple scrolling announcement bar for the GOLF PAGE ONLY. Black band,
  white uppercase copy, lime/green dots between phrases. Looping marquee that
  pauses on hover and honors reduced-motion.

  HOW TO USE
  1. Create sections/avro-golf-ticker.liquid and paste this entire file in.
  2. On the golf page template, add this section to the TOP of the page
     (drag it above the golf section in the theme editor).
  3. Phrases come from "Message" blocks — add / remove / reorder them, or edit
     the text. With no blocks added it shows the default AVRO Golf phrases.
     Background, text color, dot color and scroll speed are all editable.
  ============================================================================
{%- endcomment -%}

{%- comment -%}
  GOLF-PAGE GUARD. This section renders ONLY on the golf page, even if it gets
  added to another template. We match the golf page from its handle, its page
  template suffix, or the URL path (/golf). Set the handle(s) in "Golf page
  handle(s)" if your golf page uses a different handle. Turn the guard off only
  if you deliberately want the ticker on every page it's placed on.
{%- endcomment -%}
{%- assign gt_render = false -%}
{%- if section.settings.golf_only == false -%}
  {%- assign gt_render = true -%}
{%- else -%}
  {%- assign gt_handles = section.settings.golf_handles | default: 'golf' | downcase | replace: ' ', '' -%}
  {%- assign gt_list = gt_handles | split: ',' -%}
  {%- for h in gt_list -%}
    {%- if h != blank -%}
      {%- if page.handle == h -%}{%- assign gt_render = true -%}{%- endif -%}
      {%- if template.suffix == h -%}{%- assign gt_render = true -%}{%- endif -%}
    {%- endif -%}
  {%- endfor -%}
  {%- unless gt_render -%}
    {%- if request.path contains '/golf' -%}{%- assign gt_render = true -%}{%- endif -%}
  {%- endunless -%}
{%- endif -%}
