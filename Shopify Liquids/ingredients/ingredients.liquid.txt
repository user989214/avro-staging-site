  ============================================================================
  AVRO — INGREDIENTS PAGE  (Shopify Online Store 2.0 section)
  ----------------------------------------------------------------------------
  Mirrors the live Next.js /ingredients page:
    1. Hero (card) — "Every ingredient, fully disclosed." + 4 designation badges
    2. "What every box has in common." — 6 detail cards + caffeine footnote
    3. "Three stacks. Six flavors. Nothing hidden." — 3 stacks, each with two
       flavor Supplement Facts panels + other-ingredients text + footnote
    4. Product cards — Calm / Focus / Energy with Best For + caffeine line
    5. Ingredient FAQ  →  Final CTA  →  bottom banner  (on a deep base band)

  HOW TO USE
  1. Create sections/avro-ingredients.liquid and paste this entire file in.
  2. Images render from hardcoded live-site URLs by default — no asset upload
     needed. Pick an image in the theme editor to override any of them.
       · Badge icons default to /images/icons/
       · Supplement Facts panels default to /images/supplement-facts/
       · Product tubes default to /images/tubes/studio/
  3. Add the section to a page template, or place it via the theme editor.
  4. Every heading, body, badge, detail card, stack, flavor panel, product card
     and FAQ is editable. Badges, detail cards, stacks, products and FAQs are
     blocks — add / remove / reorder them.
  ============================================================================
