  ============================================================================
  AVRO — TERMS OF SERVICE  (Shopify Online Store 2.0 section)
  ----------------------------------------------------------------------------
  HOW TO USE
  1. Create sections/avro-terms.liquid and paste this entire file in.
  2. Add it to a page (e.g. a "Terms of Service" page) via the theme editor.
  3. FULLY CUSTOMIZABLE in the theme editor:
     • Hero: title, lede, headline animation toggle, hero card background.
     • Meta: show/hide the "last updated" date + the date text.
     • Table of contents: optional auto-built list of every Policy section.
     • Layout: reading-column width.
     • Content blocks (add / remove / reorder, up to 50):
         - Policy section  → eyebrow + heading + subheading + rich body
         - Subsection      → smaller sub-heading + rich body (nests under a section)
         - Rich text       → free body text, no heading
         - Callout         → highlighted note box
         - Divider         → thin rule between sections
  Matches the live AVRO site: rounded base-light hero card with a soft
  radial gradient and a weight-900 animated headline, then a constrained
  reading column. No images required.
  ============================================================================
